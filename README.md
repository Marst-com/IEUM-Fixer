
# IEUM Fixer

AI-Powered Project Recovery System

## Features

- ZIP project upload
- Multiple file upload
- Drag and drop
- Project explorer
- JavaScript syntax analysis
- CSS brace analysis
- HTML tag analysis
- JSON validation
- Safe typo repair
- ZIP export

## Requirements

- Modern web browser
- Internet connection for JSZip CDN

## Run

Open index.html in a browser.

No Node.js backend required.
